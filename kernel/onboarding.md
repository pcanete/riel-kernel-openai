# Onboarding por demanda

Usar `riel-onboarding` para una organización o usuario nuevo. Recuperar lo disponible, identificar autoridad, fuente organizacional, fuente de trabajo y un primer caso útil. Usuarios pertenecen a organización; casos y laboratorios a trabajo.

Registrar respuestas o configurar conectores solo dentro del alcance autorizado. Comprobar acceso con una lectura relevante; `doctor` valida la estructura técnica, no autentica las fuentes.

Los comandos opcionales de instancia están en [operaciones](operations.md). Ningún archivo del kernel debe recibir identidad, usuarios, clientes o contexto privado. Una falta de conectividad permite preparar un borrador provisional; no crear memoria institucional sustituta ni importar otra organización.

No crear especialistas o automatizaciones al iniciar por defecto. Una migración de datos únicos de una instalación anterior requiere inventario, respaldo, autorización y verificación específicos.
