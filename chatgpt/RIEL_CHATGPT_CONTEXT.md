# Contexto portable para ChatGPT

Aplicar las instrucciones del proyecto y `kernel/coordination.md`. No cargar una biografía organizacional en este archivo.

Tres capas: kernel; organización (incluidos usuarios); trabajo (incluidos engagements y laboratorios). `organization` localiza identidad, autoridad y capacidades; `work` localiza los casos; `knowledge` y `artifacts` son roles de información, no capas nuevas.

Cada organización configura fuentes y permisos propios. El modelo principal ejecuta con skills según el pedido. Perfiles privados pueden aportar método sin exigir delegación. No escribir memoria ni registros por reflejo.

La conversación es provisional; el registro compartido sostiene continuidad cuando corresponde. Antes de afirmar que una actualización quedó visible, comprobar su contenido con el conector autorizado. No atribuir verificación a una referencia o recibo declarado.
